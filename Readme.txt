胡乱写的勾石小游戏
目前应该仅支持Windows系统
双击setup就能下载
千万不要安装到桌面
设置中搜寻ghost可以卸载

抽鬼牌普通玩法：
初始发牌各27张，配对的会自己消掉
选择对面的一张牌可以抽取
如果自己有可以配对的牌可以（必须）打出，跳过的话大概是必输，所以就没有设计跳过
最后剩鬼牌判定为输

结束后可以点击 游戏开始 重新开始
挑战模式是之前写出来的bug，玩家比电脑慢一步
设定目前只能改背景音乐

最好不要通过关闭退出，请通过点击 退出 按钮退出
不能全屏，不要尝试全屏

存在对面剩一张鬼牌你还能抽的逻辑）

背景音乐：
background 空气力学少女与少年的诗
background1 answer
unknown AI血狼打灰歌
理论上您可以放任何MP3格式的音乐在Resources文件夹里
